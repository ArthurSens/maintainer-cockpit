# Support

Maintainer Cockpit is community-supported software.

- Ask installation, configuration, and usage questions in GitHub Discussions.
- File a GitHub Issue for a reproducible bug or already-agreed enhancement.
- Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

Before asking for help, use the newest published release or identify the exact
`main` commit under evaluation. Run `config-check` and `setup-check`, and
review [Troubleshooting](docs/troubleshooting.md). Include the output of
`maintainer-cockpit version`, the deployment method, relevant sanitized logs,
and the exact error. Never include tokens, private keys, session cookies, model
payloads, or private maintainer state.

Only the newest pre-1.0 release is supported. Response times are best effort;
there is no service-level agreement.
