# Governance

Maintainer Cockpit currently uses a single-maintainer model. Arthur Sens is the
project maintainer and has final responsibility for roadmap, releases,
security response, repository administration, and accepting contributions.

Decisions should be explained in public issues, pull requests, or Discussions
when they do not contain security-sensitive or private information. The
[project overview](README.md) defines enduring product boundaries, and
accepted implementation work is tracked in GitHub Issues.

Regular contributors may be invited to review or maintain an area after
sustained, constructive participation. Adding or removing maintainers is
announced publicly with the affected responsibilities. This document will be
updated before adopting a multi-maintainer decision process.

The project does not promise compatibility or support beyond the policy in
[RELEASES.md](RELEASES.md).
